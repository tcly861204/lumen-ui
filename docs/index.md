## 为什么换成 VitePress

相比 Storybook，VitePress 更适合承载组件官网文档：结构清晰、页面编排自由、中文说明和 API 表达更自然，也更容易做出接近 Element 官网的阅读体验。

## 当前文档内容

- 指南：安装、按需引入、主题换肤
- 组件：Button、Input、Tag、Icon、Form、FormItem
- 文档内示例均为真实 Vue 组件预览，并支持源码展开与复制
